# PrimeVue from a CDN

A single HTML page that loads Vue, [PrimeVue](https://primevue.dev) and the Aura preset from unpkg, with no build step.

## Run it

Open `index.html` in a browser, or serve the folder with any static server.

## Where to look

- `index.html` loads the scripts from unpkg, creates the Vue app and sets up PrimeVue with the Aura preset.

Read more in the [PrimeVue CDN guide](https://primevue.dev/cdn).
